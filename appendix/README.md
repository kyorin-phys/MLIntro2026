## きっかけ

学内の医師から、次の趣旨の依頼がありました。

> 生成 AI を活用したプログラミングに興味があり、Python への応用方法を知りたい。最終的には PyRadiomics による特徴量抽出と、機械学習への応用を考えている。

これに答えるため、PyRadiomics の入門ノートブックを作りました。別の医師からも「XGBoost を使った分類器の作り方」について同じような依頼があり、XGBoost の入門ノートブックも作りました。

当初は依頼者に直接渡すつもりでしたが、ほかの学生も使えるように、Appendix としてこのリポジトリに置くことにしました（2026-11-02）。

## 作り方

コードと説明文は、すべて生成 AI（Claude Code、Gemini）との対話で作りました。作成者はコードを書いていません。作成者が行ったのは、作りたいものを言葉で伝えること、実行して確かめること、分かりにくい点や問題点を指摘して直させることです。この作り方そのものが「生成 AI で Python を活用する方法」の実例になるので、各ノートブックの冒頭にも明記しています。

### radiomics_intro.ipynb（2026-11-02）

1. 入門ノートブックの土台を作る：人工の球で特徴量を比べ、PyRadiomics のテスト画像（脳腫瘍の MRI、`brain1`）で特徴量を抽出する
2. 見せ方を工夫する：plotly による 3D 表示、スライスを動かすスライダー（ipywidgets）、3D 図を横に並べる表示を加える
3. 機械学習につなげる：良性・悪性を模した人工データを分類する章を加える
4. Colab で動かす：通常の `pip install pyradiomics` は Colab で失敗する。Gemini との試行で見つかった手順（新しい NumPy を先に入れ、`--no-deps` で本体を入れ、依存ライブラリを手で足す）に置き換える
5. 内容を直す：作成者の指摘をもとに、次の点を直す
   - A と B の比較表を見やすくする
   - 「専門家ではない者が書いてよいのか」という問いから、範囲の注記と「範囲と注意点」の節（IBSI・RQS・CLEAR）を加える
   - MRI の画素値を正規化する設定にする
   - 自分のデータで試すときの個人情報の注意を加える

### xgboost_intro.ipynb（2026-11-02）

1. 両眼のデータを模した人工データで、XGBoost の分類と評価を学ぶノートブックを作る
2. 作成者の指摘をもとに、次の点を直す
   - 決定木とランダムフォレストを先に見せてから XGBoost に進む構成に組み直す
   - 特定の診療科に寄りすぎない汎用の内容にする
   - 第3回と重なる混同行列の説明を削る
3. 「1人に目が2つある」ことによる情報漏れ（眼単位で分けると成績が見かけだけ良くなる）を、落とし穴の章として残す
